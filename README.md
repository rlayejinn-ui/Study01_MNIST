# 손글씨 숫자 인식기 (MNIST + PyTorch)

마우스로 숫자를 그리면 CNN 모델이 0~9 중 어떤 숫자인지 알아맞히는 프로그램입니다.

## 구성 파일

| 파일 | 설명 |
| --- | --- |
| `model.py` | CNN 모델 구조 정의 (학습·추론이 공유) |
| `train.py` | MNIST 데이터로 학습하고 `mnist_cnn.pt` 저장 |
| `draw_app.py` | 마우스로 숫자를 그려 인식하는 GUI 프로그램 |
| `mnist_cnn.pt` | 학습된 가중치 파일 |
| `data/` | 자동으로 내려받은 MNIST 데이터셋 |

## 사용 방법

1. 학습 (가중치 파일 생성)

```bash
python train.py
```

2. 손글씨 인식 프로그램 실행

```bash
python draw_app.py
```

## 사용 팁

- 검은 칸 **가운데에 크게** 숫자 하나만 그리세요.
- `Enter` 키: 인식하기 / `Esc` 또는 `Delete` 키: 지우기
- 오른쪽 막대그래프에서 0~9 각각의 확률을 확인할 수 있습니다.

## 모델 구조

`합성곱(1→32) → 합성곱(32→64) → 맥스풀링 → 드롭아웃 → 완전연결(9216→128) → 드롭아웃 → 완전연결(128→10)`

손실 함수는 음의 로그우도(NLL), 옵티마이저는 Adadelta(학습률 1.0, 에폭마다 0.7배 감소)를 사용합니다.
